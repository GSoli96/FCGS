============================================================
COMANDI DA ESEGUIRE DIRETTAMENTE SUL PC (dopo ssh <pc>)
============================================================
Una volta dentro la sessione SSH, usa questi comandi — nessun problema di quoting.

AVVIO: usa wmic se disponibile, altrimenti Start-Process (PowerShell).
  wmic non disponibile su Windows 11 recenti → usa Start-Process.

 ---
  MSI  (path: C:\Users\giand\Desktop\prog\FCGS)

  # Avvio
  cd C:\Users\giand\Desktop\prog\FCGS
  wmic process call create "cmd.exe /c cd /D C:\Users\giand\Desktop\prog\FCGS && venv\Scripts\python.exe federated_grid_search.py"

  # PID (aspetta 5 secondi)
  powershell Get-Content log\log_MSI\bootstrap.log

  # Log in tempo reale
  powershell Get-Content log\log_MSI\main.log -Wait -Tail 30

  # Kill FCGS
  wmic process where "Name='python.exe' and CommandLine like '%federated_grid_search%'" delete

 ---
  Domino12  (path: C:\Users\dastl\Desktop\Giando\FCGS)

  cd C:\Users\dastl\Desktop\Giando\FCGS
  wmic process call create "cmd.exe /c cd /D C:\Users\dastl\Desktop\Giando\FCGS && venv\Scripts\python.exe federated_grid_search.py"

  powershell Get-Content log\log_MSIDomino12\bootstrap.log

  powershell Get-Content log\log_MSIDomino12\main.log -Wait -Tail 30

 ---
  Domino11  (path: C:\Users\domin\Desktop\prog\FCGS)

  cd C:\Users\domin\Desktop\prog\FCGS

  powershell Get-Content log\log_MSIDomino11\bootstrap.log

  powershell Get-Content log\log_MSIDomino11\main.log -Wait -Tail 30

  wmic process where "Name='python.exe' and CommandLine like '%federated_grid_search%'" delete

============================================================
KILL PER PID (se wmic lascia worker orfani)
============================================================
  Il PID lo trovi nel bootstrap.log: "main() avviato (PID XXXXX)"
  Poi killa workers orfani (processi python.exe in Services con tanta RAM):

  taskkill /F /PID XXXXX
