  Linux (geosciences)

  # 1. Crea il venv
  python3 -m venv venv

  # 2. Attiva il venv
  source venv/bin/activate

  # 3. Aggiorna pip
  pip install --upgrade pip

  # 4. Installa i requirements
  pip install -r requirements_linux.txt

  # 5. Installa PyTorch con CUDA (separato, adatta cu126 alla versione CUDA della macchina)
  pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126

  # 6. Verifica
  python -c "import torch; print(torch.cuda.is_available())"


   ---
  Note importanti

  CUDA version: su geosciences hai CUDA 13.0 — verifica che cu126 sia compatibile. Se torch.cuda.is_available() restituisce False, prova con cu124 o cu128.

  TenSEAL: richiede Python ≤ 3.11. Se hai 3.12+ l'installazione fallisce. Controlla con python --version prima di procedere.

  Avvio (uguale su tutti):
  # Attiva il venv se non è già attivo, poi:
  python federated_grid_search.py
